🎯 QUICK START
════════════════════════════════════════════════════════════════════════════════

1. SETUP BACKEND
   cd backend
   pip install -r requirements.txt --break-system-packages
   cp .env.example .env
   # Add ANTHROPIC_API_KEY to .env

2. SETUP FRONTEND
   cd frontend
   npm install

3. START APPLICATION
   ./start.sh

4. OPEN BROWSER
   http://localhost:3000
